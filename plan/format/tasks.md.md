# Change `tasks.md` 格式

## 位置

```text
spec/changes/<status>/<kind>/<id>/tasks.md
```

## 格式

```markdown
# tasks

## 1. 认证逻辑

- [ ] 1.1 实现风险评估输入，并验证低风险登录不会进入二次验证。
- [ ] 1.2 实现验证码挑战校验，并验证错误和过期验证码均被拒绝。

## 2. 验证

- [ ] 2.1 增加端到端登录测试，并验证高风险登录在验证成功后创建会话。
```

## 规则

- 顶层标题必须为 `# tasks`。
- 每个任务组使用 `## <number>. <title>`。
- 每个任务必须为 `- [ ] <number>.<number> <description>` 或完成后的 `- [x] ...`。
- 任务编号在整个文件中唯一；任务按依赖顺序排列。
- 每个任务描述必须包含可执行的工作和验证方法。
- CLI 只以 checkbox 作为任务状态来源：`[ ]` 为未完成，`[x]` 或 `[X]` 为完成。
