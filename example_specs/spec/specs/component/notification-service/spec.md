# contract

## [delivery] 恢复通知投递

### 职责

通知服务接收认证服务提交的恢复通知请求，使用项目配置的邮件服务向已绑定地址投递，并返回通知编号。凭证过期后停止投递。

### 边界

认证服务提供通知内容、目标地址和失效时间。通知服务只处理投递，身份验证及密码更新由认证服务负责。

## [retry-policy] 临时投递失败重试

邮件服务报告临时错误时，通知服务在有效期内最多重试两次。地址无效和恢复凭证过期属于终止条件。每次重试沿用同一通知编号。

## [delivery-status] 投递状态回执

通知服务按通知编号向认证服务返回待投递、已投递或失败状态。回执不包含通知正文、目标地址或恢复凭证。

## [receipt-query] 通知回执查询接口

通知服务按通知编号向原发起方返回当前投递状态和最后更新时间。

找不到该发起方的回执时，返回不存在；不回传通知正文和目标地址。
