# contract

## [service-boundaries] 身份平台服务边界

```text
身份平台
├── 认证服务：登录、会话、恢复凭证和密码更新
└── 通知服务：恢复通知的投递和重试
```

认证服务掌握账号凭据和认证结果。通知服务只处理投递所需的信息。

## [data-flow] 恢复校验与通知数据流

```text
浏览器 → 认证服务 → 通知服务 → 邮件服务
                ← 投递状态 ← 通知服务
浏览器 → 认证服务 → 凭证验证 → 密码更新
```

恢复通知和状态通过通知编号关联。认证服务统一验证凭证和有效期，并在同一凭证累计五次失败后拒绝后续验证。
